# Flight Aviation App 

Это приложение на Spring Boot для управления данными об авиарейсах. Система позволяет управлять пассажирскими и грузовыми рейсами, пилотами и аэропортами, предоставляя RESTful API для создания, чтения, обновления и поиска информации.

Приложение демонстрирует использование принципов ООП (наследование, полиморфизм) в сочетании с реляционной базой данных через JPA (Hibernate).

## 🛠 Технологический Стек

*   **Язык**: Java 21
*   **Фреймворк**: Spring Boot 3.5.10
*   **Сборка**: Gradle
*   **База данных**: PostgreSQL
*   **ORM**: Spring Data JPA (Hibernate)
*   **Утилиты**: Lombok (для сокращения шаблонного кода)
*   **Валидация**: Hibernate Validator
*   **Контейнеризация**: Docker (опционально)

## 🏗 Архитектура и Модель Данных

Проект использует классическую трехслойную архитектуру:
`Controller` (REST API) -> `Service` (Бизнес-логика) -> `Repository` (Доступ к БД).

### Основные Сущности (Entities)

База данных спроектирована с использованием стратегии **Single Table Inheritance** (Одна таблица для иерархии классов).

1.  **Flight (Абстрактный класс)**
    *   Базовая сущность для всех рейсов.
    *   Хранится в таблице `flights`.
    *   Поля: `id`, `flightNumber`, `departureAirport`, `arrivalCity`, `arrivalTime`, `delay`, `pilot`.
    *   Колонка-дискриминатор: `flight_type` (значения: `PASSENGER`, `CARGO`).

2.  **PassengerFlight (Пассажирский рейс)**
    *   Наследуется от `Flight`.
    *   Дополнительное поле: `passengerCount` (количество пассажиров).

3.  **CargoFlight (Грузовой рейс)**
    *   Наследуется от `Flight`.
    *   Дополнительное поле: `cargoWeight` (вес груза).

4.  **Pilot** и **Airport**
    *   Связанные сущности (Many-to-One).

### 🧠 Бизнес-Логика: Расчет Приоритета

В системе реализован полиморфный метод `calculatePriority()`, который рассчитывает приоритет обслуживания рейса в зависимости от его типа:

*   **Пассажирский рейс**:
    $$ Приоритет = Количество Пассажиров \times Время Задержки $$
     Чем больше людей ждут и чем дольше задержка, тем выше приоритет.

*   **Грузовой рейс**:
    $$ Приоритет = Время Задержки + (Вес Груза / 100) $$
    Учитывает задержку и вес груза (тяжелые грузы добавляют приоритет).

## 🚀 Установка и Запуск

### Предварительные требования
*   JDK 21
*   PostgreSQL

### Настройка Базы Данных

1.  Создайте базу данных PostgreSQL с именем `JavaLearn`.
2.  Настройте подключение в файле `src/main/resources/application-local.yaml` (или `application.yaml`):

```yaml
spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/JavaLearn
    username: postgres # Ваше имя пользователя
    password: rootroot # Ваш пароль
```

### Запуск приложения

Используйте Gradle Wrapper для запуска:

```bash
# Mac/Linux
./gradlew bootRun

# Windows
gradlew.bat bootRun
```

Приложение будет доступно по адресу: `http://localhost:8080`

## 📡 Документация API

Базовый URL: `/api/flights`

### 1. Получить все рейсы
*   **Метод**: `GET`
*   **URL**: `/api/flights`
*   **Описание**: Возвращает список всех зарегистрированных рейсов (и пассажирских, и грузовых).

### 2. Добавить новый рейс
*   **Метод**: `POST`
*   **URL**: `/api/flights`
*   **Описание**: Создает новый рейс. Тип рейса определяется полем `flight_type`.
*   **Тело запроса (Пассажирский)**:
    ```json
    {
      "flight_type": "PASSENGER",
      "flightNumber": "KC-901",
      "departureAirport": { "id": 1 },
      "arrivalCity": "Almaty",
      "arrivalTime": "2023-12-31T23:59:59",
      "delay": 15,
      "pilot": { "id": 1 },
      "passengerCount": 150
    }
    ```
*   **Тело запроса (Грузовой)**:
    ```json
    {
      "flight_type": "CARGO",
      "flightNumber": "DHL-500",
      "departureAirport": { "id": 2 },
      "arrivalCity": "New York",
      "arrivalTime": "2024-01-01T10:00:00",
      "delay": 0,
      "pilot": { "id": 2 },
      "cargoWeight": 5000.5
    }
    ```

### 3. Получить приоритетные рейсы
*   **Метод**: `GET`
*   **URL**: `/api/flights/priority`
*   **Описание**: Возвращает список рейсов, у которых расчетный приоритет выше 50.

### 4. Поиск по номеру рейса
*   **Метод**: `GET`
*   **URL**: `/api/flights/number/{number}`
*   **Пример**: `/api/flights/number/KC-901`

### 5. Поиск по городу прибытия
*   **Метод**: `GET`
*   **URL**: `/api/flights/search?city={city}`
*   **Пример**: `/api/flights/search?city=Astana`

### 6. Удалить рейс
*   **Метод**: `DELETE`
*   **URL**: `/api/flights/{id}`
*   **Описание**: Удаляет рейс по ID и возвращает удаленный объект.

### Запуск через Docker (Опционально)

Если вы хотите запустить приложение в контейнере вместе с базой данных:

1.  Убедитесь, что у вас установлен Docker и Docker Compose.
2.  Запустите команду:

    ```bash
    docker-compose up --build
    ```

Приложение будет также доступно по адресу `http://localhost:8080`.
