Практическая задача: «Система аудита аномальных перелетов»
Легенда: Ты работаешь в авиакомпании. У тебя есть текстовый файл с данными о рейсах. Тебе нужно прочитать его, отфильтровать рейсы с большой задержкой, рассчитать новое время прибытия и сохранить отчет, фиксируя каждый шаг в логах.

Этап 2: Проектирование авиационной системы

Вместо того чтобы просто парсить файл, мы создадим иерархию классов. Это позволит нам в будущем легко добавлять новые типы рейсов (например, грузовые или чартерные).
Твоя задача (Архитектура):
Создай абстрактный класс Flight:
Поля (Инкапсуляция): Номер рейса, город отправления, город назначения, время вылета (LocalDateTime), базовая задержка. Все поля должны быть private.
Конструктор: Для инициализации всех полей.
Методы: * Геттеры (только те, что реально нужны).
Абстрактный метод double calculatePriority(). У каждого типа рейса будет своя логика приоритета при задержке.
Обычный метод printInfo(), который выводит базовые данные о рейсе.
Создай интерфейс Delayable:
Метод void reportDelay(int minutes).
default метод isCriticalDelay(), который возвращает true, если задержка больше 120 минут.
Создай конкретный класс PassengerFlight:
Наследуется от Flight и реализует Delayable.
Добавь поле passengerCount.
Реализуй calculatePriority(): например, приоритет = задержка * количество пассажиров.
Создай конкретный класс CargoFlight (Грузовой):
Наследуется от Flight.
Добавь поле cargoWeight.
Реализуй calculatePriority(): например, приоритет = задержка + (вес / 100).
